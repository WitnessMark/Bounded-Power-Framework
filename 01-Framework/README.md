# Framework README

*v1 · 2026-10-21 · Published for independent review · Not adopted by anyone*

This folder holds the core documents of the Bounded Power Framework (BPF).

The framework looks at authority by its structure: what powers an authority holds, what harm each power can do, what limits it, how it can be stopped, and how it stays accountable over time.

Only one document here is binding: the **[Core Requirements (SCBP-04)](SCBP-04-Core-Requirements.md)**. Every other document explains or applies it, and where they differ, the Core Requirements govern.
