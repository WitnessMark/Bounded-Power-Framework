# Framework Background

Why the Bounded Power Framework exists, what it rests on, and how to think about its central idea. These documents explain the framework. They do **not** define it. The binding text is the [Core Requirements (SCBP-04)](../../01-Framework/SCBP-04-Core-Requirements.md); the other framework documents are in [`01-Framework/`](../../01-Framework/README.md).

New to the project? Start with [`00-Reading/`](../../00-Reading/) first.

## Contents

- [Purpose and Scope](Purpose-and-Scope.md): why the project exists, its origins and structure, and what it is and is not.
- [A Reading Note on the Framework's Reasoning](A-Reading-Note-on-the-Frameworks-Reasoning.md): a short essay on the core move, treating power as a material with size and drift rather than as a moral problem.
- [Findability](Findability.md): how the project stays discoverable and checkable without constant promotion or the maintainer's presence.

Where anything here seems to differ from the Core Requirements, the Core Requirements govern.
