# Assessments

Examinations of the framework, each made at a particular time and against a stated version. They are evaluations, not rules. Where an assessment seems to differ from the [Core Requirements](../../01-Framework/SCBP-04-Core-Requirements.md), the Core Requirements govern.

This is where independent reviews of v1 belong.

## Contents

- [Standing Positions](Standing-Positions.md): read before assessing. What stage v1 is at, which choices are deliberate, and which questions are open.
- [Answering the Circularity Objection](Circularity-Answer.md): where the strongest objection to the framework is right, and where it does not reach.

## Adding a review

A review should state the version it examined (for example, Core Requirements v1), its date, and who carried it out, by role or organization. It should say whether the reviewer is independent of the project under the Core Requirements' definition of Independent. Reviews are added as new files. An earlier review is never edited to match a later version of the framework.
