# Response — [COUNTY] Jail — to SCBP-REG-EXAMPLE-COUNTY-JAIL v1

## 1. Summary

The county announces two changes to the force power (P2) described in the record, and adds information the record did not have.

1. **An independent death-in-custody review body.** By ordinance, the County Board has created the [COUNTY] Death-in-Custody Review Board. It reviews every death of a person held in the jail and keeps the records of each death.
2. **Thresholds for force incidents.** The Sheriff has adopted, and the County Board has approved, published numeric thresholds for restraint-chair use and for force incidents. Crossing a threshold triggers a review and a public report.

This response uses the `change_notice` type because it announces institutional changes without adopting the Core Requirements. The county has not adopted the Core Requirements. The notice does not establish compliance, and the county does not claim that either change brings any finding into conformity. It asks the record's preparer to consider the changes in a new version.

## What this changes, and what it does not (non-binding reading note)

*Written by the examples working group, not by the county. It applies Core Requirements v1 to the announced changes as a preparer would when deciding whether to issue a new version.*

**Findings change only through a new version of the record, or through an authorization record.** This response changes no finding. The record's preparer may issue version 2, quoting each changed passage and citing this response. Or the county, if it adopts the Core Requirements, may file its own authorization record for P2 under 7.1. That record would sit beside the outside record and never supersede it. Until one of these happens, version 1 and this response are shown together.

**What a reader should take from this.** A change notice puts real changes on the public record next to the findings they answer, with dates and evidence. It does not let an institution grade its own changes. The county's own words, "the county does not claim that either change brings any finding into conformity", are the right posture for a response of this type.
