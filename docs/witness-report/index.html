Make a witness report

This page is open inside another app. Reports often cannot be saved from inside apps. Open it in the phone's own browser first: tap the menu (often ⋯ or ⋮) and choose Open in browser, Open in Safari or Open in Chrome.

A written account, in your own words, of something an organization or an office did, failed to do, or threatened to do. Written like a police report: when and where, who, and what happened.

If anyone is in immediate danger, emergency services come first. A report is a record, not a rescue.
  • About ten minutes. Anything not known can be left blank.
  • Nothing is sent or stored. The page works only inside this browser. At the end, the report is saved to the phone or computer, or sent wherever its author chooses.
  • Two copies at the end: a private one that keeps names and places as written, so nothing is forgotten, and one to share that uses roles: "the manager", "the officer", "the caseworker".

Map coordinates, and the file name

Coordinates only from a map app, never estimated, in decimal degrees.

File fingerprints

A code calculated from a file. A matching code later shows the file has not changed; it does not show when the file existed. The file is read only inside this browser. If the organization holds the same file, such as a letter it sent, it can match the code and learn who wrote the report.

A verification phrase

Lets a person who used a made-up name or no name step forward later. At least five random words, nothing personal. Only a code calculated from it goes in the report. Written down and kept safe first: the phrase is saved nowhere and cannot be recovered from the code.

Check and save

Which copy?

Save or send opens the phone's own menu: save to Files, email it to yourself, or send it. An email to yourself also shows when it was written.


  
After saving

  
The report belongs to its author. Nothing has been sent anywhere, and this project has no place to file reports. Save the private copy first; its file name ends in PRIVATE. Whether to share a copy, and with whom, is the author's decision: a lawyer, a legal aid service or an oversight body can act on it. Read the copy to share once as a stranger would before sending it: this page cannot find every name. The usual next steps and sharing it safely are set out in the guides.
