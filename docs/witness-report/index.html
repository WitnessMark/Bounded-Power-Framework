Make a witness report

A witness report is a dated, written account of something an institution did, failed to do, or threatened to do. It needs no proof, no special wording, no lawyer, and no one's permission.

If anyone is in immediate danger, emergency services come first. A report is a record, not a rescue.

This page asks one set of questions at a time and assembles the report as it goes. It takes about twenty minutes. Any question can be left blank: what is not known is recorded as UNKNOWN, and a report with honest gaps is more useful than none.

Privacy

  • Nothing is sent. The page works entirely inside this browser, and its security settings block every connection to the internet. It also works offline.
  • Nothing is saved. Closing the page discards what has been typed. At the end, the report is downloaded as a file that belongs to its author.
  • No photos, video or recordings. The report lists what exists and where it is kept; the files themselves stay with their owner.

Three rules

  1. Public sources and first-hand observation only. What was seen or heard, and what public records show. Nothing private, leaked or guessed.
  2. Roles, not names. "The officer", "the caseworker", "the manager". An office only one person holds, such as the Sheriff or the Mayor, identifies that person, so conduct is attributed to the office: "the Sheriff's Office".
  3. What is proven stays apart from what was seen or believed.

Where it happened

The place comes first: it is often easier to recall than the order of events, and reports about the same place can be grouped. It is given only as precisely as is safe.

Evidence

Evidence is listed, not attached. For each key claim: what it is, where it comes from, and what kind of claim it is.

A fingerprint of a file (optional)

A fingerprint is a code calculated from a file. A matching code later shows the file has not changed; it does not show when the file existed. The file is read only inside this browser and is not attached or sent.

Anonymity: if the institution holds the same file, such as a letter it sent, it can match the fingerprint and learn who wrote the report. An anonymous report leaves fingerprints out.

A verification phrase (optional)

A verification phrase lets a pseudonymous or anonymous author step forward later. The phrase is at least five random words, with nothing personal in it: no name, birthday or address. Only a code calculated from it goes in the report. If the phrase is revealed later, anyone can check it against the code. It links a person to the report; it does not prove who first wrote it.

The phrase is not saved anywhere. It is written down and kept somewhere safe first: it cannot be recovered from the code.

Keeping it

  
The report belongs to its author. Nothing has been sent anywhere, and this project has no place to file reports. A dated copy, such as an email to oneself, shows when it was written.

  
Sharing it

  
Whether to share it, and with whom, is the author's decision. A lawyer, a legal aid service or an oversight body can act on it. The text is shared, not the original photos; a pseudonymous report uses a separate email address; and the institution itself is sent a report only after retaliation has been considered. The Witness Report Guide covers sharing in full, and What You Can Do sets out the usual next steps.
